# ============================================================
# OPTIMIZATION STANDARDS
# ============================================================

## Alt Text Requirements
- Every image MUST have descriptive alt text
- Alt text should describe the image content AND include brand name
- Alt text length: 50-125 characters
- Include relevant keywords naturally

## File Naming Convention
- Use descriptive names with brand identifier
- Separate words with spaces or hyphens
- Include category or product identifier

## Compression Guidelines
- JPEG quality: 80-90% for photos
- PNG: Use for logos and graphics with transparency
- SVG: Use for icons and simple graphics
- Target file size: Under 200KB for thumbnails, under 1MB for full-size

## Modern Format Support
- Provide WebP alternatives when possible
- Use srcset for responsive images
- Implement lazy loading for below-fold images

## Lazy Loading
- Add loading="lazy" to images below the fold
- Critical above-fold images should load eagerly
- Thumbnail images in sidebar load eagerly (visible on page load)

## Responsive Images
- Provide multiple sizes via srcset when possible
- Use appropriate sizes attribute
- Ensure images look good on mobile (320px) to desktop (1920px+)
